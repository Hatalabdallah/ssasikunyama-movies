# Contributing

Thank you for your interest in contributing to Ssasikunyama Movies! Please feel free to put up a PR for any issue or feature request.

Even if you have little to no experience with React or TypeScript, we'll be more than happy to help :)

## Communication

Please don't hesitate to reach out via email at a.ddumba@kyakabi.com! Technical points of discussion, general questions and suggestions or anything at all - we would love to chat about it.

## Reporting issues & features requests

If you notice any bugs in the app, see some code that can be improved, or have features you would like to be added, please create a [bug report](https://github.com/Hatalabdallah/ssasikunyama-movies/issues/new?template=BUG_REPORT.md) or a [feature request](https://github.com/Hatalabdallah/ssasikunyama-movies/issues/new?template=FEATURE_REQUEST.md)!

If you want to open a PR that fixes a bug or adds a feature, then we can't thank you enough! It is definitely appreciated if an issue has been created before-hand so it can be discussed first.

## Working on issues

Please feel free to take on any issue that's currently open. Feel free to resolve any issue that you would enjoy working on even if it happens to be a low priority.

## Development Setup

To get started with Ssasikunyama Movies development:

```bash
# Clone the repository
git clone https://github.com/Hatalabdallah/ssasikunyama-movies.git

# Install dependencies
npm install

# Start development server
npm run dev
```
